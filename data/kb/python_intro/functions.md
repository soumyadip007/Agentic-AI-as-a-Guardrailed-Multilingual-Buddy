# Functions

A **function** packages reusable logic under a name.

## Definition

```python
def greet(name):
    return f"Hello, {name}"
```

## Key facts

- Parameters receive input values; `return` sends a result back
- Call a function with parentheses: `greet("Ada")`
- Docstrings describe purpose; keep functions focused on one job

## Scope

- Variables assigned inside a function are local unless declared `global`
