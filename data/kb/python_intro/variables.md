# Variables

A **variable** stores a value in memory under a name.

## Key facts

- Assignment uses `=` : `x = 10`
- Names should be descriptive: `score`, not `s`
- Types are dynamic in Python: the same name can later hold a different type
- Reassignment changes the value: `x = 10` then `x = 20`

## Common mistakes

- Using a variable before assignment causes `NameError`
- Confusing `=` (assignment) with `==` (comparison)
