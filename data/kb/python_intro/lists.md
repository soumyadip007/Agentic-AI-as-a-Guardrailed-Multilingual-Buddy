# Lists

A **list** is an ordered, mutable sequence of items.

## Basics

- Create with brackets: `nums = [1, 2, 3]`
- Index from zero: `nums[0]` is the first element
- Slice: `nums[1:3]` returns a sublist

## Common operations

- `append(x)` adds at the end
- `len(nums)` returns length
- Lists can hold mixed types, but usually keep one type for clarity
