# Conditionals

**Conditionals** choose which code runs based on a Boolean test.

## Structure

```python
if score >= 90:
    grade = "A"
elif score >= 70:
    grade = "B"
else:
    grade = "C"
```

## Key facts

- Comparison operators: `==`, `!=`, `<`, `>`, `<=`, `>=`
- Combine with `and`, `or`, `not`
- Indentation defines the block under each branch
