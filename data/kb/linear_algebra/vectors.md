# Vectors

A **vector** is an ordered list of numbers representing magnitude and direction in space.

## Key facts

- 2D vector: $\mathbf{a} = (a_1, a_2)$
- Addition is component-wise: $(a_1, a_2) + (b_1, b_2) = (a_1+b_1, a_2+b_2)$
- Scalar multiplication: $c(a_1, a_2) = (c a_1, c a_2)$
- Dot product: $\mathbf{a}\cdot\mathbf{b} = a_1 b_1 + a_2 b_2$
