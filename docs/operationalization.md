# Operationalizing Translanguaging

García et al. Stance / Design / Shifts → TL-Guard constructs.

| Principle | Computational construct |
|---|---|
| **Stance** | System prompt welcomes mixing; languages logged in session state |
| **Design** | Frozen Scaffold Map + curriculum KB (not a live teacher matrix editor) |
| **Shifts** | Per-turn Decide from mastery + intent + Scaffold Map; Act uses retrieved $K_t$ |

Legitimate L2 clarification is allowed under Scaffold Map clamps. Adversarial answer-seeking after a language switch triggers **tighten** (fixed rule), not a teacher escalation workflow.
