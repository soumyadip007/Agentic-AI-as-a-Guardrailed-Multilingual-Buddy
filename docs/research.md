# Research context

TL-Guard implements the paper direction:

**Agentic AI as a Guardrailed Multilingual Buddy: Translanguaging Support Under Pedagogical Safety Constraints**

## Research questions (summary)

1. How can García’s Stance / Design / Shifts be operationalized for an AI tutor?  
2. Can a Language–Scaffold Matrix keep pedagogical safety while supporting translanguaging?  
3. Can the harness distinguish legitimate vs adversarial language-switching?  
4. Does the guardrailed buddy improve outcomes vs English-only / unguardrailed multilingual baselines?  

## Contributions targeted

- Computational Stance/Design/Shifts mapping  
- LSM teacher policy artifact  
- Translanguaging-aware disclosure contracts  
- Language intent classifier  
- Empirical evaluation (planned; see `plan.md` and `research_plans.md`)  

## Shared vs distinct work

This repo is **independent** of EduHarness and of the XL-CRA risk-accumulation paper. Future work may share *ideas* (e.g. risk signals), not code dependencies.

Full literature and methodology notes live in the repository file `research_plans.md` (Paper 2 section).
